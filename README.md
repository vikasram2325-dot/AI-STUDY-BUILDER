# 🤖 AI Study Builder

## 📌 Project Overview

**AI Study Builder** is an AI-powered learning application designed to help students study smarter and more efficiently. It uses Artificial Intelligence to generate personalized study materials based on the topics or subjects provided by students.

The system helps students create notes, summaries, quizzes, and important questions, making learning easier, faster, and more effective.

## 🎯 Objectives

- To make learning easier with Artificial Intelligence.
- To generate study materials automatically.
- To save students' time and effort.
- To provide personalized learning support.
- To improve students' understanding of different subjects.

## ✨ Features

- **AI Notes Generator:** Automatically generates notes for any given topic.
- **Smart Summarizer:** Converts lengthy content into short and simple summaries.
- **Quiz Generator:** Creates multiple-choice questions for practice.
- **Important Questions:** Generates important questions for exam preparation.
- **Study Planner:** Helps students organize their study schedules.
- **Easy Learning:** Provides simple explanations for difficult topics.
- **User-Friendly Interface:** Simple and easy-to-use design.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python
- **AI Integration:** Google Gemini API
- **Database:** MySQL / SQLite (based on implementation)
- **Development Tool:** Visual Studio Code

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/AI-Study-Builder.git
```

### 2. Open the Project Folder

```bash
cd AI-Study-Builder
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure API Key

Create a `.env` file and add your Google Gemini API key:

```env
GEMINI_API_KEY=your_api_key_here
```

### 5. Run the Application

```bash
python app.py
```

Open the application in your browser using the local URL displayed by your server.
